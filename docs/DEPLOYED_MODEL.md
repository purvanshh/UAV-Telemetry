Scope: **telemetry anomaly detection only**. A flag means the window's reconstruction error exceeded the threshold; it is not a fault diagnosis.

## Model

- Architecture: `LSTMAE` (hidden 48, latent 12, layers 1)
- Variant: `conservative`
- Input shape: `(batch, 30, 12)` — 30 samples × 12 features
- Score: mean squared error between input and reconstruction over all 30×12 standardized values
- Checkpoint: `uav_model/lstm_autoencoder.pth` — sha256 `1de2bfbaf90ca3239dd1001dd0db5cc68bd4ecbef0868acea4a07b467f396af7`

## Preprocessing

- Alignment grid: 10 Hz, gap-aware linear interpolation; values are not interpolated across source gaps > 0.5 s
- Session break: source gap > 1 s (windows never cross sessions)
- Windows: 30 samples (3 s), stride 15 samples (1.5 s); a window with any non-finite deployed feature is discarded and counted
- Timestamps: `TimeUS` = microseconds (explicit); numeric `Timestamp` = microseconds by schema default (rate-checked); other units/datetime strings are rejected. Event times are the source log clock in seconds (see `src/timebase.py`)
- `preprocessing.py` sha256 `d13b0e5d389e9abf137782d5632da07b1710e8131764c076e29da81912513249`
